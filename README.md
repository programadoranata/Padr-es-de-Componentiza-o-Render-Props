# Padr-es-de-Componentiza-o-Render-Props

## Mouse Tracker

Desafio de lógica reutilizável com Render Props.

### Objetivo
Rastrear a posição do mouse e aplicar em diferentes componentes sem repetir código.

### Funcionamento
- **MouseTracker**: Monitora coordenadas X e Y.
- **Texto**: Exibe os números das coordenadas.
- **Círculo**: Segue o cursor usando estilos dinâmicos.

### Técnicas
- Prop `render` para expor o estado.
- `useState` e `useEffect` para eventos de mouse.
- Posicionamento absoluto.
